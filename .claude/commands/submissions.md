# submissions

Every submission with its outcome and how long the regulator took.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs submissions --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Newest first. Nothing here lodges with a regulator or pays an invoice.
