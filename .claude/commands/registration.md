# registration

One registration in full: dates, submissions, labels, conditions, sales, declarations, renewals, fees and history.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs registration "<registration>" --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Read this before drafting anything about a registration. Nothing here lodges with a regulator or pays an invoice.
