# weekly-review

Draft the Monday registrations review from attention, due and compliance.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs weekly-review --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Open the draft, check it reads right, and say where it is. Nothing is sent. Nothing here lodges with a regulator or pays an invoice.
