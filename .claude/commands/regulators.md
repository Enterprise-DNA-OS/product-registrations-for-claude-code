# regulators

The regulators set up, their country and how their registrations renew.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs regulators --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Add a regulator with /customise. Nothing here lodges with a regulator or pays an invoice.
