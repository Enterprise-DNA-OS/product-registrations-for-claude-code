# obligations

Open obligations from conditions and commitments, soonest first.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs obligations --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Name the owner of each. Nothing here lodges with a regulator or pays an invoice.
