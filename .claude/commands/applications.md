# applications

Submissions still waiting for a decision, and how long each has waited.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs applications --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Longest waiting first. Name the owner of each. Nothing here lodges with a regulator or pays an invoice.
