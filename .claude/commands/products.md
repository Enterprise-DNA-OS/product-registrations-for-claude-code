# products

Products with how many current registrations each has, and in which markets.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs products --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. One line per product. Nothing here lodges with a regulator or pays an invoice.
