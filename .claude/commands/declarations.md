# declarations

Levy, annual return, $0 turnover and AICIS declarations for the latest periods, and which are in.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs declarations --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Say what is still to lodge and by when. Nothing here lodges with a regulator or pays an invoice.
