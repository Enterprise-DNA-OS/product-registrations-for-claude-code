# draft-levy

Draft the APVMA levy and annual return working paper for the last financial year.

Read fresh data. Never invent a registration, a date, an amount or command output.

```bash
node scripts/registrations.mjs draft-levy --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a registration or product is ambiguous, list the candidates and ask. Say the total leviable value by holder and anything missing. Nothing here lodges with a regulator or pays an invoice.
